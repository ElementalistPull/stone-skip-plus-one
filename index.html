FAQ

Questions about the +1 script

Short answers to the things people ask before downloading.

What exactly does the +1 Stone Skipping Script do?

It intercepts every skip event during a stone skipping run and adds exactly one to the count. On top of that it tracks a combo multiplier across consecutive skips, counts ricochet bounces separately, and logs a per-bounce score so you can see where the +1 gains came from.

Which Windows versions are supported?

The build is tested on Windows 10 (21H2 and later) and Windows 11. It runs as a standard user process and does not require administrator privileges or any additional runtime installations.
